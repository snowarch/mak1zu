A Go engine for a Discord companion that remembers people, has a real personality, and runs from one static binary. Her character is a Markdown file. Yours to rewrite.

Not customer support
in a costume.

A shared layer of rules for how people actually type: short, opinionated, imperfect. A small file for who the character is. A guard that strips the tells. The numbers come from measuring thousands of real replies.

  • Memory stays with the person

    What you told her, what is still open in your life, running jokes that rest between callbacks. One person across Discord and the terminal. One person's memory never reaches another's prompt. A test proves it.

  • A voice you can measure

    mak1zu eval --gate fails when she drifts. persona distill learns a character from somebody's real messages.

  • She writes first, if you let her

    A night shift that tidies memory and keeps a diary you can read. Quiet hours, a daily cap, and "stop" is honoured. Off until you turn it on.

  • She changes herself when you ask

    A new skill, a house rule, a different character. She shows the diff and applies it only after your yes in a later message.

  • Servers, DMs, house rules

    Home channels where she talks freely. Mention-only channels where only a real @mention wakes her.

  • Extensible in about 20 lines

    Tools and hooks in Go, any MCP server as a tool source, personalities in Markdown.

She cannot read your files or run commands from chat, by design. What has been tested live and what has not is in the roadmap, plainly.

Or by hand.

Go 1.27 or newer. Putting her in a Discord server takes a bot token and one intent switch; the setup guide walks through it.

# install
$ git clone https://github.com/snowarch/mak1zu ~/src/mak1zu
$ cd ~/src/mak1zu && make install
# give her a home and a brain
$ mkdir ~/mak1zu && cd ~/mak1zu
$ mak1zu init
$ mak1zu doctor
# talk to her, then put her on Discord
$ mak1zu
$ mak1zu run

The panel is at 127.0.0.1:8787: a live feed of what she heard and why she stayed quiet, her models, rooms, dials and personality file. Changes apply instantly.
