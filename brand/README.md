# Brand

The name, the logo and the artwork here are Mak1zu's identity. They are for
referring to the project: links, articles, talks, screenshots. A fork or a bot
built on the engine needs its own name and art (see License below).

A halftone moon in vermilion, her in paper white, on ink black. Everything is
vector first; the PNGs are renders of the SVGs.

| File | Use |
| --- | --- |
| `banner` | README and social headers, 1500×500 |
| `social` | link preview card, 1280×640 |
| `emblem` | the mark on its own |
| `avatar`, `avatar-512` | square avatar; crops cleanly to a circle |
| `icon`, `icon-16` … `icon-256` | small sizes, no halftone (it turns to mud under 64 px) |
| `wordmark-on-dark` | for dark backgrounds |
| `wordmark-on-light` | for light backgrounds |
| `wordmark-one-ink` | single colour, for stamps and print |

Colours: ink `#121114`, paper `#F3F0EA`, vermilion `#E4412B`.

Rules: don't put a solid outline next to the halftone, don't crop the character
with plates or frames, don't use the halftone below 64 px.
