# Writing a skill

A skill is know-how for one kind of task. Keep it to a page.

- Front matter: `description:` in one line saying *when to use it*.
- Numbered steps she can follow, with concrete do/don't details.
- Say what to do when it doesn't apply, in one line.
- Put long lists in `references/<name>.md` and name them in the body.
- Rules are different: a rule is always on, so it must be short and sharp.
  If it only matters for one task, it's a skill.
